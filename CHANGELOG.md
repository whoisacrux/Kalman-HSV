# Changelog

## 1.1.0 — 2026-10-11

- Added a third desktop tab for two-dimensional synthetic motion.
- Added curved, straight and circular scene generators.
- Added noisy measurement boxes, filtered boxes, a bounded trail and a +0.4 s forecast.
- Added model uncertainty and a manual two-second observation gap.
- Added mouse controls and `--motion` / `-Motion` launch options.
- Added numerical regression tests and recorded their results.
- Added an English repository README and Turkish quick-start/upload instructions.

## 1.0.0 — 2026-10-11

- HSV webcam/color-chart mask with adjustable thresholds and cleanup.
- Independent scalar temperature Kalman simulation with a chart and CSV export.
- CMake project, Windows launcher and standalone scalar tests.
